# 常见问题与排错

以下汇总了日常使用与开发集成过程中最常见的问题解答：

### Q: 为什么两端平台的 Commit Hash 不相同？

**A**: 因为两端分别使用了不同的签名密钥和独立的 noreply 邮箱身份进行物理隔离签名。引擎通过 `mapping` 字典记录两端提交的拓扑映射关系，两端解开后的文件树（Tree Hash）保证 100% 相同。

### Q: 如果主平台遇到网络超时怎么办？

**A**: 推送流程已集成带指数退避的自动重试机制（默认最多重试 5 次），网络短暂抖动不会导致状态文件破损。

## 故障排查通用步骤

1. **核对运行环境版本**：确保您的 Node.js / Python 或浏览器版本符合最低兼容要求；
2. **检查控制台报错日志**：绝大部分配置错误或权限拒绝在控制台中都有清晰的行号与原因提示；
3. **提交 Issue 反馈**：若确认遇到底层 Bug，欢迎前往 GitHub 仓库提交复现用例与诊断日志。
